# Sprint Web Development - 03

Projeto web desenvolvido como parte da avaliação para a Sprint 03.

---

## Tecnologias Utilizadas

* **Next.js**
* **React**
* **JavaScript**
* **CSS3 / PostCSS**
* **ESLint**
* **Node.js & npm**

---

## Pré-requisitos

É necessário ter instalado em sua máquina:

* [Git](https://git-scm.com/)
* [Node.js](https://nodejs.org/)

---

## Como executar o projeto

### 1. Clonar o repositório

```bash
git clone https://github.com/RavineEnvy/sprint-js3.git
```

### 2. Acessar a pasta do projeto

No terminal, execute:

```bash
cd meu-app
```

### 3. Instalar as dependências

Ainda no terminal:

```bash
npm install
```

### 4. Executar o projeto

Execute:

```bash
npm run dev
```

### 5. Acessar no navegador

Após iniciar o servidor, copie o endereço exibido no terminal (geralmente `http://localhost:3000`) e cole-o no navegador.
